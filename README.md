# AI-Based Hand Tracking for Robotic Arm Control

A Python-based computer vision project that uses a webcam to track hand movements and control a virtual robotic arm in real time.

## Features
- Real-time hand tracking using MediaPipe
- Shoulder and elbow movement simulation
- Gesture-based gripper control
- Webcam-based interface using OpenCV
- No Arduino or physical robotic arm required

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command:

```bash
python main.py
```

## Controls

| Hand Movement | Action |
|---|---|
| Move hand left/right | Shoulder rotation |
| Move hand up/down | Elbow movement |
| Bring thumb and index finger together | Close gripper |
| Separate thumb and index finger | Open gripper |
| Press Q or ESC | Exit the application |
